# Сайт-визитка барбера

Одностраничный статический сайт. Весь код — в одном файле `index.html`
(HTML, стили и скрипты внутри). Никакой сборки, зависимостей и админки:
открывается двойным кликом, кладётся на любой хостинг копированием папки.

```
index.html         весь сайт: разметка, стили и скрипты в одном файле
img/               фотографии
favicon.svg        иконка вкладки
README.md          этот файл
build_preview.py   служебный скрипт для онлайн-превью, на сайт не влияет
```

Для публикации нужны только `index.html`, `img/` и `favicon.svg`.

## 2. Фотографии

Положить файлы в папку `img/`. В коде каждая заглушка выглядит так:

```html
<div class="ph" data-label="Работа 1"></div>
```

Заменить на:

```html
<img src="img/rabota-1.jpg" alt="Мужская стрижка, вид сбоку" loading="lazy">
```

`alt` — короткое описание того, что на фото. Его читают вслух программы для
незрячих, и по нему находят картинки в поиске; пустой `alt` — упущенная выгода.

Что нужно снять:

| Где | Сколько | Формат |
|---|---|---|
| Низ страницы | 1 | ✔ портрет Мансура в круге |
| Блок «зачем» | 1 | ✔ `img/process.webp` |
| Портрет барбера | 1 | ✔ `img/master.jpg` |
| Фото работ | 10 | 7 временных (мелкие), 3 слота пустые |
| До / после | 4 | **нужны** — 2 пары, одинаковый ракурс и свет внутри пары |
| Салон | 4 | 3 есть (`studio-1…3.webp`), 1 слот пустой |
| Отзывы | 4 | **нужны** — квадратные портреты клиентов |
| `img/og.jpg` | 1 | **нужен** — 1200×630, превью ссылки в мессенджерах |

Портрет, который уже есть, сохранить как `img/master.jpg` — в коде для него
готово место с комментарием.

Перед загрузкой сжать через [squoosh.app](https://squoosh.app) — целиться в
200–300 КБ на фото. Ширины больше 1600 px не нужно. Если сохранить в WebP,
страница будет грузиться заметно быстрее.

**Пары «до/после» важно снимать одинаково** — тот же ракурс, то же
расстояние, тот же свет. Иначе ползунок сравнивает не стрижку, а освещение.

## 4. Публикация

**GitHub Pages** — бесплатно: создать репозиторий, загрузить файлы,
Settings → Pages → Source: `main` / `root`. Свой домен — в поле Custom domain
плюс файл `CNAME` с доменом внутри.

**Обычный хостинг** — скопировать содержимое папки в корень (`public_html`).

**Обязательно https.** Без него браузеры показывают «Не защищено», а строки
`canonical` и `og:url` в коде указывают на `https://` и разойдутся с реальным
адресом. У большинства хостингов сертификат Let's Encrypt включается одной
галочкой.

## 5. Шрифт

Сейчас используется системный шрифт: он уже есть на устройстве, поэтому
грузится мгновенно и не зависит от зарубежных CDN (Google Fonts из России
открывается медленно и не всегда). Выглядит близко к Rubik с сайта-образца.

Если нужен именно Rubik — скачать с [fontsource.org](https://fontsource.org/fonts/rubik),
положить `.woff2` в `img/` (или отдельную папку `fonts/`) и добавить в начало `<style>`:

```css
@font-face{
  font-family:"Rubik";
  src:url("fonts/rubik-400.woff2") format("woff2");
  font-weight:400; font-display:swap;
}
@font-face{
  font-family:"Rubik";
  src:url("fonts/rubik-700.woff2") format("woff2");
  font-weight:700; font-display:swap;
}
```

и подставить `Rubik` первым в переменную `--font`. Нужен вариант с кириллицей
(`cyrillic`), иначе русский текст молча съедет на запасной шрифт.

## 6. После публикации

- Добавить сайт в [Яндекс.Вебмастер](https://webmaster.yandex.ru/) — он же
  проверит разметку организации
- Завести карточку в **Яндекс.Бизнесе** и **2ГИС** и указать там сайт: для
  локальных услуг это приводит больше людей, чем сам сайт
- Проверить разметку: [validator.schema.org](https://validator.schema.org/)
- Проверить скорость: [PageSpeed Insights](https://pagespeed.web.dev/)

## Что уже сделано в коде

Помимо вёрстки, здесь закрыты проблемы, найденные на сайте-образце:

- `<h1>` на странице ровно один и он осмысленный
- `lang="ru"` у `<html>` — иначе браузер не переносит слова по-русски,
  а скринридер читает текст с английским произношением
- заполнены `description` и Open Graph — превью в мессенджерах и выдаче
- `canonical` и `og:url` на `https://`
- телефон кликабельный везде, где он упоминается
- разметка `HairSalon` со всеми услугами, ценами и часами работы
- адаптив от 320 px, бургер-меню на телефонах
- клавиатурная навигация: ползунки «до/после» — стрелками, галерея и меню —
  с клавиатуры, у фокуса видимая рамка
- главный портрет грузится в приоритете, остальные фото — лениво: первый
  экран появляется быстрее
- `prefers-reduced-motion` — при включённом в системе «уменьшить движение»
  остаётся мягкое проявление, но убираются сдвиги и бегущий блик на кнопке
- появление блоков не ломается при быстром пролистывании: наблюдатель может
  не заметить блок, пронёсшийся мимо за один кадр, поэтому есть страховка,
  которая досматривает пропущенное
- если скрипт не выполнится, страница остаётся полностью читаемой: скрытие
  включается классом `js`, который скрипт сам и ставит
