# Мансур-Барбер — демо

Временная демонстрационная версия сайта-визитки. Не для публичного показа:
в `index.html` стоит `<meta name="robots" content="noindex, nofollow">`,
поисковики страницу не индексируют.

**Перед запуском боевого сайта эту строку нужно удалить** — иначе сайт
не появится в поиске. В исходном `index.html` (вне этого репозитория)
её нет.

## Из чего состоит

`index.html` — весь сайт. `js/scene.js` — звёздный фон под содержимым,
обязателен для публикации: в него вшита three.js, чтобы сайт не зависел
от зарубежных CDN. Подробности — в `README-подробный.md`, раздел
«Звёздный фон».
